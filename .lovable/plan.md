# 游客身份测试人工协助表单

## 注意
目前没有"请求列表"页面：游客提交后看不到自己的请求（他们没有账户，无法安全地只显示自己的记录）。请求列表只有您能在后台看到（Cloud → Database → `expert_help_requests`）。因此"查看请求列表"这一步将改为：在后台确认记录已保存且内容正确。

## 测试步骤（未登录）
1. 打开首页 FAQ，展开"如果报告没起作用怎么办？"，点击"申请人工协助"，确认能跳转到表单。
2. 检查错误提示：邮箱为空或格式错误、案件描述太短，都应显示提示且不提交。
3. 填写邮箱、案件描述、日期、时间段、时区、补充说明后提交，确认显示"已收到您的申请"。
4. 在后台查询该记录：邮箱、描述、日期、时间段、时区、备注都正确，且没有关联用户或案件。
5. 同一邮箱连续提交，确认第 4 次被"提交过于频繁"拦截（每天上限 3 次）。
6. 中文界面重复第 3 步，截图确认文案。
7. 只按 id 删除所有测试记录。
